# 个人电脑网络安全工具包

本工具包包含个人电脑网络安全的学习文档和自动化监测工具。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `个人电脑网络安全识别与防范指南.md` | 全面的网络安全知识文档，涵盖威胁识别、防范措施和应急响应 |
| `网络安全监测.ps1` | PowerShell 监测脚本，自动检查电脑安全状态 |
| `运行安全监测.bat` | 双击即可运行监测脚本的快捷入口 |

## 🚀 快速开始

### 运行安全监测

1. **右键** `运行安全监测.bat` → 选择 **以管理员身份运行**
2. 等待扫描完成，查看控制台输出
3. 日志文件自动保存在 `SecurityLogs` 文件夹中

### 命令行运行

```powershell
# 以管理员身份打开 PowerShell，然后执行：
.\网络安全监测.ps1
```

## 📊 监测项目

监测脚本会检查以下内容：

- **防火墙状态** — 确认所有防火墙配置文件已启用
- **杀毒软件状态** — 检查防病毒软件是否正常运行
- **网络连接** — 检测可疑的外部连接
- **开放端口** — 扫描本地监听端口，标记可疑端口
- **可疑进程** — 识别已知恶意软件进程
- **启动项** — 审查注册表启动项、启动文件夹和计划任务
- **DNS 配置** — 检查 DNS 服务器设置
- **共享资源** — 列出所有网络共享
- **Windows 更新** — 检查待安装的安全更新
- **文件活动** — 检测异常的文件修改和勒索软件特征

## ⚠️ 注意事项

- 建议以管理员权限运行以获得完整的监测信息
- 日志文件按日期保存在 `SecurityLogs` 文件夹中
- 发现 `[!!警报]` 标记的项目时，请参考防范指南进行处理
- 本工具仅用于辅助安全检测，不能替代专业安全软件
